System architecture

One measurement world. Clear responsibility boundaries.

Sensors stay rigid and calibrated. The arm changes object pose; deterministic robotics systems own motion and safety. Hermes and local models only orchestrate approved high-level jobs.

01 · Sensor frame

Seal Lite

Fixed geometry sensor. Defines the scan-world coordinate frame and records multi-view mesh data after the arm settles.

02 · Vision frame

IMX219 Stereo

Fixed RGB/stereo reference. Captures texture images, detects part state and checks blur, framing and visibility.

03 · Motion

reBot B601-DM

Holds a validated carrier, presents approved viewpoints and executes regrip through safety docks.

04 · Edge control

Jetson Orin ×2

Jetson A: ROS 2, MoveIt, arm/stage and watchdog. Jetson B: camera capture, OpenCV and quality checks.

05 · Reasoning

Mac Studio M5 Ultra

Hermes, local LLM/VLM, RAG, mesh processing, TRELLIS.2 experiments and curated LoRA evaluation.

Approved capture workflow

Every job creates a complete, replayable episode.

The first production skill is scan_part_in_hand_v0. It works from an approved viewpoint library rather than generating improvised robot poses.

S1–S3

Receive & authorise

Create a task ID, route to an approved skill and request an operator check for unfamiliar parts or new fixtures.

S4–S6

Bring up & inspect

Verify ROS 2 lifecycle state, storage, sensor health and calibration versions. Fail closed to safe park.

S7–S9

Safety gate

Verify hardware E-stop, protective stop, workspace state, payload and collision envelope before motion.

S10–S12

Capture & verify

Move, settle 0.8 seconds, capture geometry and locked RGB frames, then calculate coverage and quality.

S13–S15

Log & learn

Write immutable metadata. Update RAG facts. Promote skills or LoRA candidates only after evaluation.

Geometry pass

Measure first.

  • Seal Lite remains stationary on a rigid, strain-relieved mount.
  • reBot moves only between approved view IDs and waits for vibration to settle.
  • Coverage failure permits one approved rescan cycle, then asks for review.
  • Use physical caliper measurements to establish real scan-cell accuracy.
Colour pass

Colour is a camera problem.

  • IMX219 captures left/right RGB reference frames at matching viewpoint IDs.
  • Lock exposure and white balance; use controlled diffuse lighting.
  • Record camera calibration and colour target/profile versions.
  • Project RGB frames onto the final mesh only after geometry registration.

Safety boundary

LLM has no direct motor authority.

Hermes may select an approved capture profile, query RAG, start a high-level job, request an operator check and request a safe stop. It may not issue raw torque commands, modify joint limits, cancel hardware E-stop, or invent trajectories outside the approved planning layer.

Hermes / Local LLM └── approved_job(profile_id) └── ROS 2 + MoveIt + collision checker └── controller limits + watchdog └── hardware E-stop / protective stop
Milestones

Start with repeatability, then add intelligence.

M0 · Bench foundation

Safe, rigid, observable cell

Fixed mounts, lighting, carrier/docks, independent E-stop, cable strain relief, sensor and robot bring-up.

M1 · Geometry benchmark

Prove 0.5 mm against physical measurement

Ten scans of one simple reference part; compare at least ten features to caliper measurements.

M2 · Automated capture

Run scan_part_in_hand_v0

Capture eight to twelve approved viewpoints, RGB frames, raw scan data and immutable episode metadata.

M3 · Regrip coverage

Expose occluded surfaces safely

Use a dock and second carrier pose to scan accessible reverse-side geometry without collision.

M4 · Hermes orchestration

High-level local-agent operation

A Cantonese request selects a safe approved profile and produces a report; abnormal states stop safely.

M5 · Curated learning loop

RAG facts, governed skills, evaluated LoRA

Only human-approved successful episodes and labelled corrections become training candidates.

First Cursor tasks

  • Create ROS 2 package skeletons and lifecycle node contracts; use mock hardware first.
  • Implement a versioned calibration registry and job-directory writer.
  • Add safe-home/park-only motion test for reBot before capture poses.
  • Create a physical test-plan sheet for M1 caliper comparisons.

Definition of done

  • All artifacts are timestamped and traceable to calibration/profile versions.
  • No raw datasets, ROS bags or secrets are committed to Git.
  • Every hardware command has a stop/failure route and a documented owner.
  • New skills are versioned and evaluated; they are not silently accumulated.
  • Any new LoRA adapter is tested offline, replayed and dry-run before promotion.
